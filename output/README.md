# 2026 주요업무계획 추진현황 대시보드

## 어떤 파일을 열어야 하나요?

**`2026_업무추진현황_대시보드.html`** — 이 파일 하나만 더블클릭하세요.

이 파일은 차트 라이브러리와 데이터가 모두 안에 들어 있는 **완전한 단일 파일**입니다.
- 인터넷 연결이 없어도 작동합니다.
- 다른 폴더로 옮기거나, 이메일로 보내거나, USB에 담아도 그대로 열립니다.
- 다른 파일이 필요 없습니다.

## 주요 기능

- **KPI 요약**: 전체 과제 수, 평균 이행률, 추진완료·추진중 건수
- **부서별 평균 이행률** 막대차트 (8개 부서)
- **추진 상태 분포** 도넛차트
- **과제 목록**: 검색 + 부서/상태 필터 + 정렬 (전체 118개 과제)
- **진행 수정**: 각 과제의 상태·이행률·메모를 직접 업데이트 (브라우저에 자동 저장됨)
- **CSV 내보내기**: 현재 목록을 엑셀로 저장
- **원본 복원**: 직접 수정한 내용을 원본으로 되돌리기

## 매달 데이터 갱신하는 법

새 엑셀이 나오면 알려주세요. 데이터만 교체해서 대시보드를 갱신해 드립니다.
